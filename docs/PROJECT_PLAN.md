# Project Plan and Portfolio Evidence

## Eight implementation phases

1. **Setup:** Install Python, create a virtual environment, install dependencies.
2. **Data input:** Generate synthetic responses or map a CSV export to the required schema.
3. **Cleaning:** Normalize categories, parse dates, remove duplicate IDs and invalid rows.
4. **EDA:** Inspect response counts, distributions, missing values and dates.
5. **Analysis:** Calculate option counts/shares and group-level distributions.
6. **Visualization:** Produce bar, pie, regional stacked, demographic heatmap and weekly trend charts.
7. **Insights:** Generate descriptive summaries and state limitations.
8. **GitHub:** Add documentation, screenshots, tests, and push incremental commits.

## Five-day schedule

- Day 1: Set up project, dependencies and README outline. Commit: `chore: initialize project structure`.
- Day 2: Generate synthetic dataset and validate schema. Commit: `feat: add synthetic poll data generator`.
- Day 3: Add cleaning, vote-share calculations and tests. Commit: `feat: implement poll cleaning and analysis`.
- Day 4: Add charts, insights and dashboard. Commit: `feat: add visual reports and Streamlit dashboard`.
- Day 5: Capture screenshots, review README and push to GitHub. Commit: `docs: add project screenshots and usage guide`.
